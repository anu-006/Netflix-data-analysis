Netflix Data Analysis Dashboard
1. Project Title / Headline
Netflix Insights: Movie Data Analysis and Dashboard  
An analytical project combining Python and Power BI to explore Netflix movie data, uncovering trends in genres, popularity, ratings, and release patterns.

2. Short Description / Purpose
This project provides a comprehensive analysis of Netflix movies using Python for data cleaning and statistical exploration, and Power BI for interactive dashboard visualization. It helps analysts and enthusiasts understand which genres dominate, how ratings vary, and how Netflix’s catalog has evolved over time.

3. Tech Stack
Python – Data analysis and exploration
pandas, NumPy – Data cleaning and transformation
matplotlib, seaborn – Statistical visualization in Python
Power BI Desktop – Interactive dashboard creation
Power Query – Data shaping and preparation
DAX (Data Analysis Expressions) – Custom measures for KPIs and Top 10 analysis
File Formats – .csv dataset, .ipynb notebook, .pbix dashboard

4. Data Source
Dataset: mymoviedb.csv (offline dataset).

Structure:
Movie attributes: Title, Genre, Release_Date,Original Language,Poster URL
Engagement metrics: Popularity, Vote_Count, Vote_Average
Derived fields: Category (popular, average, below_avg), Top 10 films, total films per year

5. Features / Highlights
Business Problem  
Entertainment platforms often need to identify which genres and films resonate most with audiences, and how catalog growth aligns with viewer satisfaction.

Goal of the Project  
To deliver a combined analytical workflow that:
Uses Python for data cleaning, transformation, and statistical insights.
Uses Power BI for interactive dashboards and storytelling.
Highlights genre distribution and popularity.
Tracks catalog growth and rating trends over time.
Identifies Top 10 films by popularity or votes.

Walkthrough of Key Visuals
KPI Cards: Total Films, Sum of Vote Count,Most Pouplar Genre,Most Pouplar Film
Genre Analysis: Bar chart for popularity by genre, pie chart for category distribution
Top 10 Films Table: Titles ranked by Max Popularity
Trends: Line charts showing total films by year, Max Popularity by year, and Vote Average distribution

Business Impact & Insights
Content Strategy: Identify genres with high popularity but low ratings
Audience Engagement: Spot blockbuster films and analyze their vote counts
Trend Analysis: Track catalog growth and shifts in audience preferences
Marketing Optimization: Promote genres with strong ratings and high engagement
